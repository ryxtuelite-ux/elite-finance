# EliteFinance V1.0

Ứng dụng quản lý thu chi cá nhân responsive, dùng trên máy tính và điện thoại.

## Tính năng
- Dashboard tháng: tổng thu, tổng chi, tiết kiệm, tỷ lệ tiết kiệm và tổng số dư.
- Thêm, sửa, xóa và lọc giao dịch.
- Quản lý tiền mặt, ngân hàng và ví điện tử.
- Ngân sách theo danh mục.
- Mục tiêu tiết kiệm và nạp thêm tiền.
- Báo cáo theo tháng và xuất CSV.
- JSON Backup/Restore để chuyển dữ liệu giữa thiết bị.
- Light/Dark mode.
- Lưu dữ liệu bằng IndexedDB, không dùng localStorage.
- PWA/offline khi chạy qua HTTP/HTTPS.

## Sử dụng
Máy tính: giải nén rồi mở `index.html`.
Điện thoại: để dùng ổn định và cài như ứng dụng, đặt thư mục trên máy chủ HTTPS hoặc chạy bằng local HTTP server.

## Chuyển dữ liệu
Cài đặt → Xuất JSON → lưu vào OneDrive → trên thiết bị khác chọn Nhập JSON.
